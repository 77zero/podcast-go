# ADR-0001 逐字稿：粗粒度时间轴 + Markdown 交付物

- 状态：已接受（2025-XX-XX）
- 背景依据：`<本地路径>`（最小能力包、文件交付原则）

## 背景

转写逐字稿原先按 whisper 分段逐句带时间戳展示，且产物为 `.txt`，需要用户手动复制。
时间轴的真实用途是让 AI 对长文本先分段总结、再汇总总结，降低幻觉与焦点丢失；
精细时间轴既不服务于该目的，也增加阅读负担。

## 决策

1. **粗粒度时间轴**：逐字稿（界面与 .md 产物）按固定 15 分钟分组，段头只保留起止时间；
   段内为连续正文，不带逐句时间戳。`.json` 仍保存完整分段时间作为权威数据源。
2. **自动生成 .md 交付物**：转写完成即生成 `.md`（替代 `.txt`），
   提供「打开 MD 文件 / 在文件夹显示」一键获取，不再依赖手动复制。

## 影响

- 逐字稿更贴合「喂给 AI 做分段总结」的工作流；阅读更清爽。
- 不新增依赖、不改变 json 数据结构；向后兼容（旧 json 仍可读）。
